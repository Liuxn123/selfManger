# 当前源码说明（2026-10-30）

Hermes 和通用 Agent 备份、记录读取与恢复入口已移除。旧版 Agent 备份说明与验证记录仅供历史参考，不能作为当前功能或验收证据；原资料、登记和旧备份未自动删除。

## 当前数据安全恢复范围

- 资源级 `.amb` 备份可校验后恢复到新目录或空目录；归档中的路径可按组件选择新目录。恢复只写入目标，不覆盖原目录，并在发布前逐文件核验哈希。
- “数据库与 Markdown 整体备份”包含 `manager.sqlite3`（含应用自有工作笔记）、个人计划 Markdown、登记项目 Markdown 和 `projects.json`。旧 `work-summary.md` 首次读取时导入数据库并保留原件。它不含知识库正文/附件、项目非 Markdown 附件、凭据或指定系统/依赖目录。
- 整体备份先恢复到新的空目录，保存隔离数据库 `manager.sqlite3.recovered`，并生成阻止误启动的空 `manager.sqlite3`。先核对提取结果，不要手动改名数据库。
- 数据安全页的“准备可用数据目录…”可从该隔离目录另行生成一个全新目录。程序验证清单中的文件哈希、检查数据库完整性，把数据库复制到新 `data` 目录，并将备份中的个人计划 Markdown 和项目 Markdown 恢复到新目录；SQLite 中已知的个人目录、工作区及导入标记路径随之重映射。现有隔离恢复目录及隔离数据库保持不变。
- 若备份记录了 Obsidian 知识库路径，界面可选择映射到这台电脑已有的知识库。知识库正文、附件、项目非 Markdown 附件、凭据不包含在整体备份中，不会被复制。映射报告会列出未找到的个人文档和外部引用；孤儿记录保留，不自动删除。未显式映射的外部路径保留原值。
- 准备完成后，核对目标目录中的 `恢复后启动说明.txt` 与 `恢复映射报告.json`。以新 `data` 目录启动：`selfManger.exe --data-dir "<目标目录>\data"`。应用不会替换当前运行实例或自动重启；切换前应确认项目工作区、个人目录及知识库指向正确。
- 自动化恢复用例主要使用合成资料，覆盖隔离提取、校验失败拒绝发布、SQLite 打开、个人计划/项目路径重映射、知识库元数据路径重映射和原隔离数据库不变。另已对获授权的真实 SQLite 隔离副本验证 schema 升级、核心计数保留及完整性，并按数据库登记映射验证个人 Markdown 文件哈希与导入幂等；这不等同于真实 `.amb` 整体备份/恢复演练，也没有扫描整个 Vault 或项目附件。尚无可见桌面端到端验收。

# 换电脑恢复：能恢复什么

“备份与迁移”使用管家创建的加密 .amb 文件。只有实际选进备份、未被排除的文件会恢复。需要创建备份时的密码，无需先导入旧电脑的登记配置。

可以恢复：
• 项目工作文件、Markdown 笔记、图片和其他附件。
• 登记的 Agent 本地记录与配置文件，包括聊天 JSON/JSONL 和 SQLite 数据库的已提交数据。
• 多个来源目录，可在新电脑分别选择项目和记录子目录。
• 恢复完成后在管家重新登记这些新路径，原登记保留。
• 已有的 `data/asset-library` 文件留在便携目录中；技能管理已交由 Skills Manager，管家不再提供通用技能库入口。

需要你在原应用完成：
• 安装 Hermes、Codex、WorkBuddy、Obsidian 等原应用及其运行环境。
• 重新登录、核对项目路径、必要时通过原应用导入记录。文件完整不保证所有 Agent 可以直接续聊。
• 云端独有聊天需先从原应用导出；系统钥匙串、原电脑外部 SSH 私钥不会自动携带。
• 恢复的 MCP 配置还需核对服务器地址、依赖与凭据；管家不自动启用外部工具。

备份默认排除 .git、虚拟环境、依赖目录、缓存与临时文件。普通项目没有 Git 提交历史；myself 等明确启用独立 Git 管理的知识库可以另存历史文件，但不自动拼装新 .git。备份设置里的额外排除也会生效。

恢复到新文件夹或空文件夹；先查看清单，非空目标会被拒绝。完成后核对文件、应用路径和登录，再使用原应用。

验证情况：
• 已用全新的管家登记和另一目标目录执行图形界面恢复流程：解密、预览、恢复、自动登记。中文项目文件、聊天文件、二进制附件、SQLite 内容均核对一致。
• 自动测试覆盖错误密码、篡改、目标冲突、链接拒绝、SQLite WAL 快照及旧包兼容；打包验证包含解压启动与整个便携目录迁移。
• 这些是数据恢复验证；没有声称每个 Agent 的旧会话都已在原客户端接续，也没有执行生产服务器切换。

Hermes 原生快照与 .amb 不同：本地 Hermes 在对应页面使用原工具恢复，可能替换当前资料，先保存当前版本；服务器 Hermes 恢复到远端空目录，不自动启动网关。它们的备份仓库与密码材料也需要另行取得。
