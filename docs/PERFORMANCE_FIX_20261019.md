# 项目管理与今日工作台点击停顿修复

日期：2026-10-19；任务：T-110。对应诊断：`PERFORMANCE_REVIEW_20261019.md`。

## 已实施的修改

1. **项目页不再递归扫描目录来更新按钮。** 原先 `update_selection_actions()` 每次都会同步调用 `project_git_repositories()`，递归搜索到四层目录；选中项目、回调和页签切换会重复调用。现在只有用户点击 Git 状态时才后台发现仓库，随后读取 Git 状态；选择变化后丢弃过时结果。打开模块和切换页签不再等待目录发现。
2. **切换模块不再启动旧资料兼容导入。** 启动检查保留，零新增不广播刷新三个页面；工作台自身后台刷新仍检查新增旧日记录，保留外部资料增量导入。未变化的迁移标记不写回数据库。
3. **页面读取不先写操作历史。** 为 Worker/submit 增加独立的 `record_history` 参数，仅项目列表、项目详情、行动读取和知识扫描显式关闭；默认仍开启。备份、恢复、导入、保存、完成任务等业务操作保持原来的审计行为。页面读取完成不再刷新系统口令和隐藏设置状态。
4. **项目读取共用一次经过验证的登记快照。** 每个后台读取操作内复用登记表；文档访问仍逐次执行路径与联接边界检查。刷新重新创建快照，不跨刷新永久缓存，不用该快照写登记。
5. **详情解析与查询移到后台。** STATUS 解析、HANDOFF 分段/概览摘要、里程碑解析、关联任务及完成状态查询在后台准备；UI 使用准备好的结果更新控件。最近使用时间也在后台保存，并使用重新读取的登记表执行冲突检查。
6. **减少重复渲染和隐含写入。** 同一次选择缓存与重读报告相同则不重复渲染；切项目页签只切换显示，不自动执行“同步任务文档”。显式同步按钮保留。
7. **补齐旧控件的生命周期。** 仍被兼容回调引用的隐藏旧页面由主窗口保留引用，避免操作记录控件已销毁后被回调访问。

本轮没有更换 Qt/SQLite，没有扩大线程池，也没有跳过项目路径保护。知识库扫描事务本身的增量化属于后续性能项；本轮解决了页面读取为写任务记录而等待该事务的问题。
