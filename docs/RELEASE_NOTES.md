# selfManger 更新记录

## v1.0.1

- 软件目录、Python 包与入口、窗口品牌、图标资源、GitHub 仓库、CI 产物和 Windows 包统一更名为 `selfManger`。
- 本机数据目录与系统凭据服务使用 `selfManger`；环境变量改为 `SELFMANGER_DATA_DIR`，项目初始化配置与 Skills 副本改为 `.selfManger/`，工作台资料默认存放 `myself/selfManger`。
- 提供独立的一次性迁移工具，迁移前保存并校验快照，保留数据库记录与用户原文；应用不保留旧名称的运行时回退。升级方式见 [迁移说明](RENAME_MIGRATION.md)。
- 保持原有六页工作台与通用四步项目初始化流程；不重建 Agent 管理系统。历史版本和已生成的加密归档保留。
- 此版提供 Windows 64 位便携包。针对改名、迁移、初始化和数据保护进行了验证；旧界面/性能测试仍有不匹配与超时，全量回归及其他平台尚未通过，详见 VALIDATION.md。

## v1.0

- 项目初始化改为四步引导，仅提供通用内置模板并支持自定义模板和规范；选中的 Skills 完整复制到项目，配置写入 `.xiaonian/config.json`，规则通过 AGENTS.md 提供入口。
- 项目提供初始化/接手提示词，明确每轮状态、任务与交接动态的维护约定；进度按用户维护的里程碑展示。
- 知识库改善主题导航、收件箱、资料收集及浅深主题/窄窗口显示。
- 数据安全统一归档位置，增加文件夹/脚本备份、可读版本目录、口令持久化和单版本删除入口。
- 精简导航并暂停专用 Agent 管理，保留已登记资料的数据保护能力；计划和工作台呈现尚未完成的历史任务。
- 此次为软件源码更新，安装包、跨平台运行效果和人工验收以对应验证记录为准。

## v0.8.3

- 数据安全首页重排为统一的备份目标 / 登记项选择器、常用操作栏和状态卡。
- 汇总最近备份、恢复检查、运行 / 连接与资料范围，并提供按 Agent 类型适配的更多操作菜单。
- 备份历史、换电脑恢复、操作记录、保护概览和底层备份 / 恢复流程继续复用既有实现。

## v0.8.2

- 设置页拆分为资料目录、备份目录、统一备份密码和可选维护卡片，右侧集中显示目录与密码状态。
- 修复设置保存后状态未同步，并保留既有设置处理控件兼容。

## v0.8.1

- Agent 页面调整为列表 / 详情工作区，增加搜索、目录路径复制、资源与操作概览。
- 常用入口、记录、备注、登记、目录、备份恢复继续连接现有功能；Hermes 仍使用既有数据安全适配器。
- 详情采用概览、最近记录、相关资源、备注、备份状态分区；相关资源继续由 Markdown 资源库提供。

## v0.8.0

- 项目归档 / 重新启用改为更新 STATUS 生命周期字段，项目目录和 Obsidian 链接保持原位。
- 归档时保存原项目状态，重新启用时恢复原状态；旧归档无记录时安全回到“进行中”。
- 项目筛选、索引、工作台展示和编辑保护统一依据 STATUS 状态，兼容历史上实际存放在 `archive/` 的项目。
- 目标 / 进展 / 风险卡片可直接编辑 STATUS，下一步卡片可编辑 TASKS；总结与最近记录有对应快捷操作，仍追加到原 HANDOFF。
- 项目状态卡片增加“编辑项目状态”，直接编辑原 STATUS Markdown，保存后刷新卡片。
- 保留旧移动 API 和旧 `L-` 归档接续能力；不改项目登记格式、备份、恢复或便携数据格式。

## v0.7.5

修复项目归档与重新启用的操作闭环，保持原数据格式。

- 成功后切换到对应项目分类并选中原编号，刷新 Obsidian 真源与今日状态。
- 移动失败记录增加失败步骤、系统错误与状态；核对文件一致后明确提示未移动，已移动的中断继续保留现场核对。

- 不修改项目登记、SQLite、每日 Markdown、备份 / 恢复 / 加密或便携路径格式。

## v0.7.0

产品重心调整为每天开始 Agent 工作的个人工作台。一级导航缩为今日、项目、Agent、资源库、数据安全、设置。

## 本次变化

- 今日成为默认首页。日程与可勾选任务保存每日 Markdown，Obsidian 外部编辑自动刷新；显示继续项目、最近进入和待处理异常。
- 项目保留既有规范，新增可自定义阶段、下一步概览、关联 Agent / 资源。八栏目阶段总结追加到 HANDOFF，提供可复制生成 Prompt 与人工编辑。
- Agent 统一常用入口、记录、目录、Markdown 备注与相关资源，Hermes 深度管理沿用原 Adapter。
- 资源库用统一 frontmatter 管理 Prompt、Skill、MCP、工具与资料，支持搜索、收藏、类型 / 项目 / Agent 筛选，正文与 Obsidian 共用。
- 备份恢复、校验、演练、换电脑、历史与必要诊断集中数据安全。隐藏重复旧工作笔记入口，原文件保留并可查阅。
- 文件读写有大小 / 路径限制与编辑冲突保护；读取在后台完成。进程检测仅保护概览按需运行。

## 兼容性

配置只增加 workbench_schema=1 和可选资料路径；不升级 .amb 格式、不重写 projects.json、不改变旧登记 id。旧项目缺少阶段字段仍能查看；保存新字段才修补 STATUS。原加密、迁移、便携路径与 Obsidian 项目联接继续使用。

资源库登记状态由用户填写，不能当成已执行安装 / 测试的证据。本版不连接 MCP，不自动调用 AI，不实现云盘、邮件、日历或自动协作平台。

## 验证

自动化测试覆盖原备份 / 恢复 / 加密 / 快照 / 迁移 / 便携 / 项目 / Obsidian，以及新增每日任务保存、外部刷新、资源创建搜索收藏、数据兼容和“今日 → 项目 → 总结 → 资源”GUI 链路。也覆盖旧阶段进展原文保护、关闭期间后台读取、未配置 Agent 和合法系统目录别名。

本机 Windows 运行 105 项测试：103 项通过，2 项因符号链接权限限制跳过。窗口响应测量约 0.71 秒构造与显示、14 秒运行期最长界面心跳间隔约 77 毫秒（11 项登记的独立副本，不包含打包运行时加载）。完整结果见 [验证记录](VALIDATION.md)。其他平台通过现有 CI 构建验证，不把本机结果表述为所有电脑实测。

macOS 原子保存的文件通知增加可见首页的轻量读取兜底；只读取今日文件，不周期性扫描项目。监听路径按差异更新，保留已存在的目录监听。
