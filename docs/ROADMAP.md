# selfManger 路线图与历史规划

## 当前源码路线（2026-11-01）

本节描述当前源码方向；下方 v0.x 计划保留作历史记录，不代表当前功能或未完成事项。项目级执行状态保存在运行工作区的 Agent 文档中，不随本源码仓库分发。

- **数据统一：**个人行动、计划、复盘和项目任务在当前源码中以 SQLite 为应用真源。旧个人 Markdown、旧项目 `TASKS-AI.md` / `TASKS-MANUAL.md` 仅一次性导入并保留原件；项目 `agent/TASKS.md` 是开发协作清单，不导入业务任务。字段、关系、迁移和回退由合成数据及隔离样本验证；自动化样本不代表完整用户工作区或 Vault 验收。
- **知识与项目：**知识正文/附件留在文件，SQLite 管理索引、元数据、外部引用和资源组。Catalog 已退出，旧 Catalog 文件仅保留一次性迁入知识库入口。项目身份/路径由 `projects.json` 管理，生命周期来自 STATUS，Agent 协作文档继续是文件。
- **代码治理：**UI 保留展示、交互和异步状态，业务规则集中到服务与 Store；页面不因体积而机械拆分。项目级执行状态由运行工作区管理，不在源码仓库副本中维护。
- **备份恢复：**保留 `.amb` 校验/提取及整体备份隔离数据库。整体恢复准备路径可生成新数据目录并重映射已知路径；迁移、完整性与回退由合成数据和隔离样本覆盖。Vault 正文/附件与系统凭据不属于整体备份范围。
- **运行验证：**自动化回归、隔离客户端流程与手动视觉体验是不同验证范围；全量测试通过不能替代目标 Windows 环境中的实际体验复核。
- **边界：**不接触真实业务库或真实 Vault，除非获得明确授权；不恢复已移除的 Hermes / 通用 Agent 管理和备份系统，不重新引入 Markdown 双向任务同步。

## 历史版本计划快照

以下内容按原样保留以供追溯；其中关于 Markdown 写任务、活动 Catalog、Hermes 和通用 Agent 管理的条目已被当前架构取代，不作为现行路线。

## Agent 管理 · 暂缓

- 暂不提供 Agent 管理入口、状态面板或 Skills Manager 启动入口。
- Agent 的备份、校验和恢复继续由数据安全页提供。
- 本机已有 Skills 的只读发现仍供项目初始化选择使用。

## 基础模块补齐

- 工具整合复用资源库 Markdown，登记软件/网站启动目标并安全地打开。
- 设置页提供持久化的浅色/深色外观选项，并继续管理资料目录、备份目录和维护设置。
- 项目页补充按需只读查看 Git 分支与已跟踪文件状态；不自动拉取或提交。
- 按模块完成后集中进行用户界面验收，再决定是否扩展更深的 Git 操作和 Agent 配置集成。

## 计划模块 · 当前按模块验收

- 新增独立计划入口，提供日历日期选择、周 / 月 / 自选范围和跨日事项列表。
- 用 Markdown 管理长期目标、周期任务、复盘和计划模板；项目时间线可按关联项目编号筛选。
- 周期任务按规则投影到日历，只有用户点击“加入每日计划”才写入每日 Markdown；模板写入选定日期并保留原文冲突保护。
- 计划首页按最近反馈收敛为周计划与单一时间线；其他基础模块与整体体验仍需结合实际使用评估。

## v0.8.3 · 数据安全工作区

- 资料保护页只列出已登记且支持备份的本机资料，显示副本时间、校验状态和下一步操作。
- 找回资料页按资料浏览可恢复版本；继续后复用现有解锁、内容检查、目标选择与恢复确认流程。
- Hermes 使用原生恢复流程；项目、Vault 与 Agent 使用 `.amb` 归档。页面不承诺保护云端独有内容或应用账号。

## v0.8.2 · 资源库与设置整理

- 资源库采用分类 / 项目筛选、资源列表和详情三栏展示，补充标签筛选、收藏优先排序和资源元信息。
- 设置页将资料目录、备份目录、统一密码与可选维护整理为卡片，并在侧栏汇总连接状态。
- 不调整备份格式、Markdown 资源格式、Obsidian 路径或 SQLite schema。

## v0.8.1 · Agent 工作区

- Agent 页面采用左侧可搜索列表、右侧详情和分区标签。
- 集中展示最近使用、路径、最近操作、相关资源和备份状态。
- 常用操作保持复用现有登记、资源库和数据安全功能。

## v0.8.0 · 项目状态归档与可编辑概览

- 编号项目归档 / 重新启用只更新 STATUS 状态，不移动目录或重建 Obsidian 入口。
- 归档后可恢复归档前的生命周期状态；旧归档兼容默认恢复为进行中。
- 目标 / 进展 / 风险卡片直达 STATUS 编辑，下一步卡片直达 TASKS；总结和日志卡片提供对应快捷写入。
- 过滤、索引与工作台排除规则统一依赖生命周期状态。

## v0.7.9 · 工作台手动刷新

- 侧栏首页改名为“工作台”，外部 Markdown 更新由手动刷新载入。
- 移除首页定时重读、文件变更监听触发和切回窗口自动重读。

## v0.7.8 · 精简今日页

- 移除优先级和专注计时控件。
- 每日计划编辑后同步刷新今日任务与对应日期 Todo。

## v0.7.7 · 调整今日任务顺序

- 今日页先显示“今日要做”，再显示 Todo。

## v0.7.6 · 收简今日任务区

- Todo 可设截止日期，今日要做显示所选日期任务。
- 首页只保留两块任务清单，完整日程仍在日程总览查看。

## v0.7.5 · 归档与接续修复

- 解决 Windows 目录监听占用，归档 / 重新启用完成后恢复监听与项目选择。
- 失败保留步骤和底层原因，区分未移动与需要核对现场的中断。
- 旧归档通过新编号项目接续，沿用原规范，不搬动历史资料。

## v0.7.4 · 总体日程

- 首页默认今天，支持过去 / 未来日期选择、前后一天与回到今天。
- 二级“日程总览”统一查看未来 30 天、所有未完成任务、全部已登记事项及自选范围。
- 添加任务 / 日程可选日期；复用每日 Markdown 与 Obsidian，无外部日历平台。
- 按需后台索引与缓存，日期响应校验、原文冲突保护；不增加正文数据库或改备份格式。

## v0.7.3 · 日常入口修复

- 解决启动数据位置不一致导致的空项目，完善首次使用引导。
- 验证新建、资源关联、备注保存、缺失文档和按钮反馈。
- 优先修复日常操作闭环，维持原备份与恢复安全边界。

## v0.7.2 · 项目工作区优化

- 左侧项目卡片、右侧当前阶段与下一步，常用操作就近展示。
- 目标、进展、阶段总结、行动、风险与最近记录采用自适应卡片；保留完整原文。
- 从既有 TASKS / HANDOFF 读取真实统计，任务入口文件不推算完成率。
- 合并目录、归档和 Obsidian 索引操作；不改项目规范、SQLite、备份格式与迁移机制。

## v0.7.1 · 今日体验优化

- 根据实际试用简化首页：真实统计、今日重点、任务与时间轴、项目卡片和紧凑保护状态。
- 直接添加任务 / 日程，仍共用 Markdown；手动专注计时，不采集 Agent 活动。
- 小窗口保留任务与项目双栏，减少装饰；不引入天气服务或额外同步平台。

## v0.7.0 · 每天开始工作的个人工作台

- 默认今日：Markdown 日程 / 勾选任务、继续项目、最近使用、需要处理事项、必要备份状态。
- 项目复用 STATUS / TASKS / HANDOFF 与 Obsidian，突出阶段、下一步；自定义阶段、阶段总结与关联 Agent / 资源。
- Agent 统一日常入口、记录、目录、备注与关联资源，原登记与 Adapter 保留。
- 单一资源库登记 Prompt / Skill / MCP / 工具 / 网站 / GitHub / 文章 / 模板等，搜索、类型 / 收藏筛选、Markdown 与 frontmatter。
- 原备份、加密、校验、演练、迁移、便携和诊断集中数据安全。
- 增量配置迁移，不改旧项目注册表或备份格式；防覆盖外部编辑。

验收以“打开今日 → 进入项目 → 找 Agent 与资源 → 继续工作”为主，功能数量不是目标。

## 下一轮以真实使用决定

优先收集：今日计划是否每天会写、项目下一步是否清晰、哪些收藏经常找不到、哪些异常提示能促成处理。

可能的小改进：今日任务更方便的单项输入、选择已有 Markdown 目录的引导、关联资源的常用筛选、阶段总结 Prompt 的个人模板。先验证必要性，再实施；保留 Markdown 真源与兼容性。

如果已有安全 Agent 调用接口可复用，再考虑人工触发生成阶段总结；不为此引入复杂 AI 框架。

## 暂不实施

完整日历或 Google Calendar、Gmail / 云盘客户端、完整 MCP Host / Client、工作流引擎、多 Agent 自动编排、复杂 AI 调度、桌面 / 浏览器自动化、完整知识库 / 项目管理 / 笔记软件、替代 Obsidian。

## 必须持续保护

Hermes 原生备份 / 恢复、.amb schema 1 与解密兼容、错误密码与篡改拒绝、恢复目标防覆盖、恢复演练、凭据边界、SQLite 与聊天快照、项目编号和归档生命周期、Obsidian 真文件、U 盘路径。新增日常能力不能削弱这些保障。
